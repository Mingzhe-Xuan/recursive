# Composable Latent Computation in Atomistic Foundation Models: Recursion, Routing, and Stitching

## 1. Overall Motivation

Large pretrained atomistic models are increasingly used as general-purpose representations of atomic and crystalline systems. Models such as MACE-MP and DPA-2 are trained on broad chemical and structural distributions and are intended to transfer beyond the systems encountered during pretraining. MACE-MP-0, for example, was trained on approximately 150,000 inorganic crystal structures, while DPA-2 explicitly formulates large atomic modeling as multi-task pretraining followed by downstream adaptation.

Most current transfer-learning workflows nevertheless treat a pretrained atomistic model as a largely monolithic function,

\[
x=(A,L,P)
\longrightarrow
M(x)
\longrightarrow
y,
\]

where internal latent representations are generated in a predetermined sequence and are either read only at the final layer or fine-tuned as part of the entire network.

This project explores a different hypothesis:

\[
\boxed{
\text{Latent representations of atomistic foundation models may serve as reusable computational interfaces.}
}
\]

If this hypothesis is correct, pretrained computation might be recomposed in several ways:

1. a model's representation could be fed back into its own pretrained computation to obtain additional inference-time computation;
2. different downstream tasks could selectively read from different representation depths;
3. the representation produced by one pretrained model could be translated into a representation consumable by another model.

These three questions correspond to three increasingly strong forms of **latent composability**:

\[
\boxed{
\text{Self-recursion}
\rightarrow
\text{intra-model routing}
\rightarrow
\text{cross-model functional stitching}.
}
\]

The overarching goal is therefore to understand whether pretrained atomistic networks behave as fixed end-to-end functions or as collections of reusable physical representation and computation modules.

---

# 2. Unified Formalism

Consider a pretrained atomistic model \(M\) consisting of \(L\) representation blocks:

\[
H_0^M
\xrightarrow{B_1^M}
H_1^M
\xrightarrow{B_2^M}
\cdots
\xrightarrow{B_L^M}
H_L^M.
\]

We denote a network segment by

\[
B_{i:j}^{M}:
\mathcal H_i^M
\rightarrow
\mathcal H_j^M.
\]

Importantly, the latent space \(\mathcal H_l^M\) is more than a vector dimension. Its effective “type” may include

\[
\mathcal H_l^M
=
(
\text{channel dimensions},
\text{irreducible representations},
\text{normalization},
\text{feature statistics},
\text{semantic content}
).
\]

Atomistic computation also depends on a model-specific geometric representation

\[
G_M(x),
\]

which may include cutoff graphs, radial bases, spherical harmonics, edge embeddings, and periodic-image information.

We introduce a general latent interface

\[
S_{A,i\rightarrow B,j}:
\mathcal H_i^A
\rightarrow
\mathcal H_j^B.
\]

The three proposed projects correspond to different choices of this interface.

### Project I: Self-recursion

\[
M=A=B.
\]

Can a pretrained computation block consume a representation generated by a previous application of itself?

### Project II: Task-dependent routing

No transition between models is required. Instead, the problem is

\[
H_l^M
\rightarrow
P(H_l^M)
\rightarrow
R_t
\rightarrow
y_t,
\]

and we ask which \(l\) and which pooling operator \(P\) are most appropriate for downstream task \(t\).

### Project III: Cross-model functional stitching

\[
A\neq B.
\]

We ask whether

\[
H_i^A
\xrightarrow{S_{A,i\rightarrow B,j}}
\tilde H_j^B
\xrightarrow{B_{j:L}^{B}}
y
\]

can produce useful computation.

Together, the projects characterize the **closure, hierarchy, and interoperability** of atomistic latent representations.

# Project I — Recursive Latent Computation and Distribution Alignment

## 3. Introduction

Test-time scaling asks whether a pretrained model can improve its performance by using additional computation during inference rather than through additional parameter training.

A recurrent-depth implementation of this idea has recently been explored in language models, where a learned latent block is repeatedly applied at inference time to increase effective computation.

Atomistic models provide a particularly interesting setting for this question because message passing already has a clear physical interpretation: repeated interaction blocks propagate information across increasingly extended atomic environments. Multi-ACE formalizes equivariant atomistic models as repeated message-passing operations and explicitly separates local body order from message-passing depth.

Recursive atomistic representations themselves are not new. REANN introduced recursively embedded atom representations as part of the trained architecture and showed that recursion can increase nonlocality and many-body representational capacity.

The unanswered question considered here is different:

\[
\boxed{
\text{Can pretrained atomistic computation be reused beyond its native trained depth?}
}
\]

Given a frozen pretrained model, we investigate whether an existing computation block can be applied additional times at test time.

The primary complication is **latent distribution shift**.

A pretrained block

\[
F:
\mathcal H_a
\rightarrow
\mathcal H_b
\]

was optimized on inputs

\[
H_a\sim P_a.
\]

After recursively reusing the block, it instead receives

\[
\tilde H^{(k)}
\sim Q_k,
\]

where generally

\[
Q_k\neq P_a.
\]

We therefore investigate two linked hypotheses:

**H1. Computational closure:** pretrained atomistic computation remains useful when recursively reused.

**H2. Alignment hypothesis:** failure at larger recursive depth is at least partly caused by latent distribution drift and can therefore be mitigated by aligning recursive representations to the block's native input space.

The project consequently asks not merely

\[
\text{“Does recursion work?”}
\]

but

\[
\boxed{
\text{When does pretrained computation remain closed under repeated application, and what breaks that closure?}
}
\]

---

## 4. Related Work

REANN is the most direct atomistic precedent for recursive representations, but recursion is explicitly incorporated during model design and training.

MACE and the Multi-ACE framework clarify the distinction between local many-body order and message-passing depth. High-body-order messages can reduce the number of propagation steps required for expressive atomistic representations, meaning that recurrent depth should primarily be interpreted as increasing semi-local propagation rather than simply increasing explicit body order.

Adaptive-depth GNNs provide another neighboring direction. Adaptive Message Passing learns graph-dependent message-passing depths to mitigate underreaching, oversmoothing and oversquashing, but does so as part of end-to-end graph-model training rather than by reusing a frozen atomistic foundation model beyond its native inference computation.

Recurrent-depth test-time scaling in language models demonstrates that latent recurrent computation can provide an alternative to token-space chain-of-thought scaling, although those models are explicitly trained with recurrent computation.

The proposed work therefore occupies a different regime:

\[
\boxed{
\text{pretrained atomistic computation}
+
\text{frozen weights}
+
\text{post-training recursive reuse}.
}
\]

---

## 5. Method

### 5.1 Native representation trajectory

For structure \(x\),

\[
H_0
\rightarrow
H_1
\rightarrow
\cdots
\rightarrow
H_L
\]

is obtained from the frozen backbone.

Choose a recurrent segment

\[
F=B_{a:b}.
\]

Its native computation is

\[
H_b=F(H_a;G(x)).
\]

### 5.2 Direct self-recursion

If latent types permit direct reuse,

\[
\tilde H^{(0)}=H_b,
\]

\[
\tilde H^{(k+1)}
=
F(\tilde H^{(k)};G(x)).
\]

This is the strictest test of computational closure.

More generally, if the output and input types differ, define

\[
\tilde H^{(k+1)}
=
F(
S(\tilde H^{(k)});
G(x)
),
\]

where

\[
S:
\mathcal H_b\rightarrow\mathcal H_a.
\]

### 5.3 Latent alignment

The interface \(S\) is constrained to preserve the symmetry structure of the target backbone.

For an equivariant model,

\[
H
=
H^{(0)}
\oplus H^{(1)}
\oplus H^{(2)}
\oplus\cdots,
\]

where superscripts denote irreducible representation order.

A valid linear adapter takes the form

\[
S
=
S^{(0)}
\oplus
S^{(1)}
\oplus
S^{(2)}
\oplus\cdots,
\]

rather than arbitrarily mixing incompatible irreps.

Several levels of alignment will be tested:

\[
\text{identity}
\rightarrow
\text{normalization only}
\rightarrow
\text{equivariant linear adapter}
\rightarrow
\text{small equivariant nonlinear adapter}.
\]

A particularly attractive pretraining strategy for \(S\) requires no downstream property labels.

For ordinary model execution we observe paired representations

\[
(H_b(x),H_a(x)).
\]

We train

\[
S(H_b(x))
\approx H_a(x)
\]

on an unlabeled structure corpus.

The adapter therefore learns to map the output distribution of the recurrent segment back toward its native input representation.

### 5.4 Downstream prediction

After \(K\) recursive steps,

\[
\hat y^{(K)}
=
R_t(\tilde H^{(K)}).
\]

The backbone remains frozen.

We measure

\[
\mathcal E_t(K)
\]

together with inference cost

\[
C(K).
\]

### 5.5 Distribution-drift diagnostics

At every recursive depth, compare

\[
Q_k=\mathrm{Law}(\tilde H^{(k)})
\]

against the native representation distribution.

Diagnostics include:

\[
\|\mu_k-\mu_{\rm native}\|,
\]

covariance mismatch,

CKA,

Procrustes alignment,

MMD,

feature-norm statistics,

nearest-neighbor preservation,

and irrep-specific statistics.

A key mechanistic analysis is whether

\[
D(Q_k,P_{\rm native})
\]

predicts the onset of downstream degradation.

---

## 6. Experiments

### 6.1 Baselines

The essential baselines are:

**Original model**

\[
K=0.
\]

This establishes native pretrained performance.

**Direct recursion**

No adapter:

\[
S=I.
\]

Tests whether the pretrained latent dynamics are naturally closed.

**Normalization-only alignment**

Tests whether simple feature-scale drift explains recursive failure.

**Linear equivariant adapter**

Tests whether a low-capacity latent coordinate transformation is sufficient.

**Nonlinear equivariant adapter**

Tests whether a richer interface is required.

**Random adapter**

Controls for additional transformations or parameters.

**Reinitialized recurrent block**

Tests whether the benefit specifically comes from pretrained computation.

**Deeper independently trained model**

Tests whether recursive reuse behaves similarly to ordinary architectural depth.

**Ensemble / multi-depth prediction**

At comparable inference cost, average predictions from native-depth models rather than recursively computing new representations.

This distinguishes genuine sequential refinement from generic extra computation.

**Full fine-tuning**

Provides a task-specific upper reference point, although the objective of the proposed method is not necessarily to outperform full fine-tuning.

---

### 6.2 Benchmarks

The first experiments should use one accessible pretrained atomistic backbone, preferably MACE-MP, before introducing architectural diversity. MACE-MP is explicitly designed as a broadly transferable pretrained atomistic model.

For downstream representation evaluation, Matbench is a natural initial suite. It contains 13 standardized materials tasks spanning electronic, thermodynamic, elastic, optical and related properties, with dataset sizes ranging from hundreds to more than \(10^5\) examples.

A representative first-stage set could include:

- formation energy;
- band gap;
- dielectric/refractive properties;
- phonon frequency;
- bulk modulus;
- shear modulus.

These tasks intentionally span different physical characteristics.

For testing native energy/force capability and OOD structural behavior, Matbench Discovery provides a complementary benchmark based on stability prediction and relaxation of candidate inorganic structures.

Later validation should include another pretrained family such as DPA-2 to determine whether the phenomenon is architecture-specific.

---

## 7. Expected Results

The most informative expected outcome is a **non-monotonic recursion curve**:

\[
\mathcal E(0)
>
\mathcal E(1)
>
\mathcal E(2)
<
\mathcal E(3)
<
\mathcal E(4).
\]

Such a result would show that pretrained computation contains useful additional inference capacity, but only within a limited latent regime.

We expect distribution discrepancy to increase with recursive depth:

\[
D(Q_k,P_{\rm native})\uparrow,
\]

and potentially correlate with degradation.

If alignment is effective, the minimum may move toward larger \(K\):

\[
K_{\rm optimal}^{\rm aligned}
>
K_{\rm optimal}^{\rm direct},
\]

while reducing representation drift.

A strong result would therefore be:

\[
\boxed{
\text{recursive scaling fails partly because the representation leaves the block's native latent manifold.}
}
\]

The strongest result would show that inexpensive latent alignment restores or extends useful test-time scaling without updating the large pretrained backbone.

A negative result is also scientifically meaningful: if aligned recursion consistently fails, it would suggest that pretrained blocks are highly position-specific rather than reusable computation operators.

# Project II — Task-Dependent Optimal Representation Depth and Layer-Level Pooling

## 8. Introduction

A common transfer-learning convention is to use the final representation of a pretrained network as the generic feature for downstream prediction.

There is no fundamental reason this must be optimal.

Neural representations evolve across network depth. Early layers may retain relatively generic chemical and geometric information, while deeper layers incorporate broader structural context and become increasingly specialized toward the pretraining objective.

In molecular representation learning, recent layer-wise studies have reported that optimal intermediate embeddings can outperform final-layer representations across downstream property tasks.

Layer-wise representation probing has also begun to appear directly in materials modeling. A 2026 study extracted intermediate ALIGNN representations and evaluated their downstream usefulness, demonstrating a systematic procedure for comparing representation quality across graph-network depth.

The proposed project moves beyond identifying which layer happens to perform best on one task.

The central question is:

\[
\boxed{
\text{Do physical downstream tasks possess characteristic optimal representation depths?}
}
\]

Furthermore, extracting a graph-level representation requires a pooling operation. Consequently, the meaningful quantity may not be an optimal layer alone but an optimal **layer–pooling pair**

\[
(l_t^*,P_t^*).
\]

We therefore aim to determine whether task physics can predict both where information should be read and how atomic information should be aggregated.

---

## 9. Related Work

Layer-wise probing is widely used to understand hierarchical neural representations.

Recent molecular work systematically examined five pretrained molecular encoders across 22 ADMET tasks and reported that intermediate layers frequently provided stronger fixed representations than the final layer.

Materials-specific layer probing is more limited. The recent ALIGNN-based study explicitly extracted features from successive message-passing and GCN layers and measured their downstream property-prediction performance. On its dielectric example, later ALIGNN/readout representations were strongest, illustrating that optimal depth can be empirically investigated rather than assumed.

The Multi-ACE analysis provides an important atomistic interpretation of depth: successive message-passing operations modify the spatial and many-body structure of atomic information, so network depth corresponds partly to effective information-propagation scale.

The proposed work therefore shifts the question from

\[
\text{“Does an intermediate layer sometimes work better?”}
\]

to

\[
\boxed{
\text{“What determines the representation depth required by a physical task?”}
}
\]

---

## 10. Method

### 10.1 Layer-wise frozen probing

Given pretrained model \(M\), extract

\[
H_0^M,H_1^M,\ldots,H_L^M.
\]

For task \(t\), train the same-capacity readout on every layer:

\[
\hat y_t^{(l,p)}
=
R_t
\left(
P_p(H_l^M)
\right).
\]

The backbone is frozen.

Define

\[
(l_t^*,p_t^*)
=
\arg\min_{l,p}
\mathcal E_t(l,p).
\]

Using identical readout capacity is essential so that performance differences can be attributed to representation quality rather than downstream-model complexity.

### 10.2 Symmetry-compatible pooling

For scalar properties, begin with invariant representations.

Candidate pooling operators include

\[
P_{\rm sum}(H)
=
\sum_i h_i,
\]

\[
P_{\rm mean}(H)
=
\frac1N\sum_i h_i,
\]

and invariant norm/power pooling over equivariant channels.

Later experiments can introduce invariant attention weights:

\[
P_{\rm attn}(H)
=
\sum_i
\alpha_i(H)
h_i.
\]

Pooling should respect physical target structure.

For example, extensive quantities naturally motivate additive aggregation, while intensive quantities may favor normalized aggregation.

### 10.3 Depth profile rather than hard layer selection

A single optimal layer may not be sufficient.

Define

\[
z_t
=
\sum_{l=0}^{L}
\alpha_{t,l}
P_l(H_l),
\]

with

\[
\sum_l\alpha_{t,l}=1.
\]

The vector

\[
\boldsymbol{\alpha}_t
=
(\alpha_{t,0},\ldots,\alpha_{t,L})
\]

defines the task's **representation depth profile**.

Sharp distributions suggest a characteristic optimal depth.

Broad or multimodal distributions indicate genuinely multi-scale representation requirements.

### 10.4 Predicting optimal depth from task physics

Define a task descriptor

\[
q_t
\]

containing interpretable characteristics such as:

- local versus collective character;
- estimated physical interaction length scale;
- scalar/vector/tensor target symmetry;
- intensive versus extensive character;
- energetic/electronic/elastic/vibrational property family;
- similarity to the energy/force pretraining objective;
- derivative or response order.

We then investigate

\[
l_t^*
\approx
f(q_t,M).
\]

The progression should be:

\[
\text{simple correlations}
\rightarrow
\text{ordinal regression}
\rightarrow
\text{small interpretable model}
\rightarrow
\text{symbolic regression}.
\]

A possible physical hypothesis is

\[
l_t^*
\propto
\frac{\xi_t}{r_{\rm eff}},
\]

where \(\xi_t\) denotes an effective physical dependency length and \(r_{\rm eff}\) the amount of propagation added per representation block.

This equation is a hypothesis to test, not an assumed law.

---

## 11. Experiments

### 11.1 Baselines

**Final-layer feature**

\[
H_L.
\]

The conventional transfer baseline.

**First-layer / shallow representation**

Tests whether deeper processing is needed at all.

**Best single layer**

Oracle layer selection from validation data.

**Uniform layer average**

\[
z=
\frac1{L+1}
\sum_lP(H_l).
\]

Tests whether indiscriminate multi-level aggregation is sufficient.

**Concatenation of all layers**

Provides a high-capacity multi-scale baseline.

**Learned scalar layer mixture**

Comparable to common layer-weighting methods.

**Task-conditioned layer mixture**

Tests whether explicitly conditioning representation selection on task improves transfer.

**Fixed pooling**

One common pooling rule for every task.

**Task-dependent pooling**

Tests the separate contribution of pooling selection.

**End-to-end fine-tuning**

Provides an upper/reference regime in which the model is allowed to reorganize its internal representations.

---

### 11.2 Benchmarks

Matbench is particularly appropriate because it supplies many tasks over the same broad domain of inorganic materials while varying the physical target.

The most useful subset should contain only tasks with structural inputs where the same atomic backbone can be applied consistently.

Representative properties include:

- formation energy;
- band gap;
- dielectric/refractive response;
- phonon frequency;
- bulk modulus;
- shear modulus.

A recent materials foundation-model study has already evaluated six representative Matbench regression tasks spanning 2D exfoliation energy, phonons, dielectric response and elastic properties, demonstrating the usefulness of this subset for heterogeneous downstream-task analysis.

The long-term version of the study should expand beyond a small number of Matbench tasks. This is important because the statistical unit for learning

\[
t\rightarrow l_t^*
\]

is the number of **tasks**, not the number of crystal structures.

A broader property zoo from several compatible materials datasets would therefore be desirable if a genuine empirical depth law is to be claimed.

---

## 12. Expected Results

We expect no universally optimal layer.

Instead,

\[
l_t^*
\]

should vary across physical targets.

A plausible outcome is that some properties strongly aligned with the energy/force pretraining objective prefer late representations, while properties depending on different physical information may favor intermediate representations.

We further expect pooling and depth to interact:

\[
l_t^*(P_{\rm sum})
\neq
l_t^*(P_{\rm mean})
\]

for some tasks.

Another likely result is that hard layer selection is sometimes insufficient:

\[
\mathcal E_t(\text{layer mixture})
<
\min_l \mathcal E_t(l),
\]

indicating complementary information across depth.

The scientifically strongest outcome would not simply be an accuracy improvement, but evidence that

\[
\boxed{
\text{physical task characteristics predict preferred representation depth.}
}
\]

For example, tasks with longer effective structural dependencies may systematically prefer deeper representations.

A simple relation that generalizes across tasks and model checkpoints would be substantially more interesting than a per-task layer lookup table.

# Project III — Cross-Model Latent Interfaces and Functional Stitching

## 13. Introduction

If the first project asks whether a pretrained model can reuse its own latent computation, a natural extension is:

\[
\boxed{
\text{Can one pretrained atomistic model consume another model's representation?}
}
\]

In ordinary deep learning this question is related to **model stitching**, where the early layers of one frozen network are connected to the late layers of another through a lightweight adapter. Model stitching has been used as a functional test of whether separately trained neural representations are mutually compatible.

This question has become especially timely in atomistic modeling.

A 2026 Nature Machine Intelligence study compared seven foundation MLIPs and found substantial shared geometry across their latent atomic representations after anchor-based alignment, despite different architectures and training configurations.

That study also demonstrated what it termed zero-shot model stitching in the aligned representation space. Importantly, the demonstrated stitching was **algebraic embedding substitution**: for example, combining reaction embeddings derived from different models in a common latent coordinate system.

This leaves open a stronger functional question:

\[
\boxed{
\text{Can the intermediate representation of model A actually drive the pretrained computational blocks of model B?}
}
\]

That is,

\[
H_i^A
\rightarrow
S_{A\rightarrow B}
\rightarrow
B_{j:L}^{B}
\rightarrow
y.
\]

Success would imply that independently pretrained atomistic foundation models possess not only geometrically related representations but partially interoperable computational states.

---

## 14. Related Work

General model stitching connects frozen bottom layers from one model to frozen upper layers from another through a small learned interface. It has been proposed as a stronger test of representation compatibility than purely geometric similarity measures such as CKA.

The 2026 “Platonic representation” study provides direct evidence that modern foundation MLIPs possess a partially shared latent geometry. It compared seven models, including MACE-MP variants, MACE-OMat, Seven-OMat and Orb-v3 variants, and found global representational agreement after an anchor-based transformation, while also identifying meaningful local differences.

Crucially, the same work notes that the raw embeddings of different models are incompatible prior to transformation: dimensionality and coordinate systems vary substantially across architectures.

Thus geometric similarity alone does not establish functional compatibility.

The proposed work makes this distinction explicit:

\[
\boxed{
\text{representational alignment}
\neq
\text{computational interchangeability}.
}
\]

---

## 15. Method

### 15.1 Functional stitching

Let

\[
A=A_{1:i}\circ A_{i+1:L_A}
\]

and

\[
B=B_{1:j}\circ B_{j+1:L_B}
\]

be two frozen models.

Compute

\[
H_i^A=A_{1:i}(x).
\]

Then map it into the target latent space:

\[
\tilde H_j^B
=
S_{A,i\rightarrow B,j}(H_i^A).
\]

The hybrid model is

\[
\hat y
=
B_{j+1:L_B}
\left(
\tilde H_j^B;
G_B(x)
\right).
\]

The geometry is still processed according to model \(B\)'s native graph, radial basis and edge representation.

This is important: the proposed interface does not attempt to force model \(A\)'s graph representation into \(B\). It primarily translates atomic latent states while allowing the receiving model to reconstruct its own geometric operators from the original structure.

### 15.2 Paired latent alignment

Because both models can process the same unlabeled structure \(x\), we have paired representations

\[
(H_i^A(x),H_j^B(x)).
\]

Train the interface via latent distillation:

\[
\mathcal L_{\rm latent}
=
D
\left(
S(H_i^A(x)),
H_j^B(x)
\right).
\]

For equivariant representations this loss must be symmetry-compatible.

Possible interfaces include:

\[
\text{orthogonal/Procrustes map},
\]

\[
\text{linear map},
\]

\[
\text{equivariant block-diagonal map},
\]

\[
\text{small equivariant neural adapter},
\]

and anchor-based relative representations inspired by current cross-model alignment work.

### 15.3 Stitchability matrix

For every layer pair,

\[
(i,j),
\]

evaluate downstream performance:

\[
C_{ij}^{A\rightarrow B}.
\]

This gives a **functional stitchability matrix**

\[
C^{A\rightarrow B}
=
\begin{bmatrix}
C_{11}&\cdots&C_{1L_B}\\
\vdots&&\vdots\\
C_{L_A1}&\cdots&C_{L_AL_B}
\end{bmatrix}.
\]

This matrix can reveal whether representation depth has cross-model correspondence.

For example, perhaps

\[
A_2\leftrightarrow B_4
\]

rather than

\[
A_2\leftrightarrow B_2.
\]

This would imply that raw layer number is not a universal depth coordinate.

### 15.4 Geometric similarity versus functional compatibility

For each layer pair, compute geometric alignment metrics such as:

- CKA;
- Procrustes similarity;
- mutual nearest-neighbor overlap;
- optimal-transport distance;
- latent regression error.

Then compare them to actual stitched downstream performance.

This tests whether

\[
\text{similar representations}
\]

are necessarily

\[
\text{interchangeable representations}.
\]

That distinction is central to the project.

---

## 16. Experiments

### 16.1 Baselines

**Native target model**

\[
B_{1:L_B}(x).
\]

Defines the performance ceiling for perfectly compatible stitching.

**Native source model**

Provides contextual comparison.

**Random adapter**

Controls for interface capacity.

**Linear adapter**

The simplest learned stitching map.

**Procrustes/orthogonal alignment**

Tests whether models differ mainly by latent coordinate rotation.

**Anchor-relative representation**

A natural baseline motivated by the recent common-latent-space approach for foundation MLIPs.

**Nonlinear adapter**

Tests whether compatibility exists but requires nonlinear coordinate transformation.

**Task-supervised adapter**

Optimizes downstream property loss directly.

**Latent-only adapter**

Uses only paired representations and no downstream labels.

The comparison between these two is especially informative.

If latent-only stitching works, interoperability is a property of pretrained representations rather than a consequence of task-specific re-learning.

**Same-architecture different-checkpoint stitching**

The easiest cross-model setting.

**Different-size same-family stitching**

For example, variants of the same pretrained architecture.

**Different equivariant-family stitching**

Tests whether physical representation structure survives architectural change.

**Equivariant ↔ non-equivariant stitching**

A deliberately hard stress test.

---

### 16.2 Benchmarks

A natural shared structure corpus is MP-20 or another broad inorganic set because identical atomic environments can be passed through every model.

The recent cross-model latent-space study itself extracted embeddings for more than 27,000 MP-20 structures across seven foundation MLIPs, making it a particularly relevant distribution for representation-alignment experiments.

For functional evaluation, Matbench structure-property tasks can again provide downstream readouts, keeping Projects II and III directly comparable.

For energy/force-oriented model interoperability, Matbench Discovery provides an additional test closer to the native objective of universal MLIPs.

The model pairings should progress from easy to difficult:

\[
\text{same architecture / different initialization}
\]

\[
\downarrow
\]

\[
\text{same architecture / different size or training data}
\]

\[
\downarrow
\]

\[
\text{different equivariant architectures}
\]

\[
\downarrow
\]

\[
\text{equivariant vs. non-equivariant families}.
\]

This creates a controlled hierarchy of representational incompatibility.

---

## 17. Expected Results

We expect stitchability to be highly structured rather than uniform.

The easiest cases should be models that share architecture, symmetry conventions and training objectives.

Cross-family stitching is likely to require increasingly expressive adapters.

We anticipate

\[
C_{ij}^{A\rightarrow B}
\]

to reveal recognizable bands or regions of compatibility rather than random layer correspondences.

One important possible result is

\[
\text{high geometric similarity}
\not\Rightarrow
\text{high functional stitchability}.
\]

If so, it would demonstrate that passive representation comparison is insufficient for determining whether representations function as computational interfaces.

Conversely, successful low-capacity stitching would provide strong evidence of a reusable shared physical representation.

The strongest outcome would be:

\[
\boxed{
\text{a model trained on one dataset or architecture can provide latent state to another frozen model that continues useful physical computation.}
}
\]

Such a result would turn the idea of shared atomistic latent geometry into actual **model interoperability**.

# 18. How the Three Projects Connect

These projects form a natural hierarchy.

## 18.1 Project I asks whether computation is reusable

\[
M\rightarrow M.
\]

If self-stitching does not work even with alignment, arbitrary cross-model stitching is unlikely to be straightforward.

Project I therefore establishes the basic notion of a valid latent computational interface.

## 18.2 Project II identifies where representations are useful

\[
H_l^M\rightarrow t.
\]

It produces a map

\[
(t,M)\rightarrow l_t^*.
\]

This information directly informs Projects I and III because not all network boundaries may be equally meaningful places to insert an interface.

---

## 18.3 Project III asks whether interfaces generalize across models

\[
M_A\rightarrow M_B.
\]

It extends self-stitching from

\[
S_{M\rightarrow M}
\]

to

\[
S_{A\rightarrow B}.
\]

The conceptual progression is therefore

\[
\boxed{
\text{computational closure}
\rightarrow
\text{representation hierarchy}
\rightarrow
\text{representation interoperability}.
}
\]

# 19. A Unified Experimental Object: the Latent Compatibility Tensor

Ultimately, the three projects can be summarized through one object.

For source model \(A\), target model \(B\), source depth \(i\), target depth \(j\), task \(t\), and possibly recursive step \(k\), define

\[
\mathcal C(A,i,B,j,t,k).
\]

This quantity measures how successfully representation

\[
H_i^A
\]

can support computation/readout associated with

\[
(B,j,t,k).
\]

Special cases recover each project.

### Self-recursion

\[
A=B,\qquad i=j,
\]

with increasing \(k\).

### Task-dependent depth

\[
A=B,
\qquad k=0,
\]

while varying \(i\) and \(t\).

### Cross-model stitching

\[
A\neq B.
\]

This unified view suggests that the deeper scientific question is not simply whether atomistic embeddings are “good,” but whether they possess a predictable structure of **computational compatibility**.

# 20. Proposed Research Sequence

The three questions should not initially be implemented simultaneously.

### Stage 1 — Representation extraction infrastructure

Choose one model, likely MACE-MP, and expose

\[
H_0,\ldots,H_L.
\]

Build identical layer-wise probes and representation diagnostics.

This infrastructure supports all three projects.

### Stage 2 — Project II first-pass layer map

Layer probing is technically the lowest-risk experiment.

Construct

\[
\mathcal E_t(l,p)
\]

for several Matbench properties.

This immediately reveals whether strong task-dependent depth effects exist.

### Stage 3 — Project I self-recursion

Select layer boundaries whose latent types make self-stitching meaningful.

Measure

\[
\mathcal E(K)
\]

and representation drift.

Only then introduce alignment adapters.

### Stage 4 — Project III same-family stitching

Start with pretrained variants of the same architecture.

This distinguishes coordinate incompatibility from deeper architectural incompatibility.

### Stage 5 — Cross-family stitching

Only after same-family functional stitching is established should substantially different architectures be connected.

# 21. Main Expected Scientific Outcomes

The overall project has several possible levels of success.

### Level 1: descriptive representation science

We establish that atomistic latent representations exhibit:

- depth-dependent transferability;
- measurable recursion-induced drift;
- cross-model geometric correspondence.

This alone provides a systematic characterization of atomistic foundation-model representations.

### Level 2: predictable interfaces

We find that:

\[
t
\rightarrow
l_t^*
\]

is predictable,

and that representation drift predicts recursive failure.

The project then yields actionable rules about where and how pretrained representations should be reused.

### Level 3: functional composability

Self-recursion and cross-model stitching succeed using lightweight interfaces.

Then pretrained atomistic models become partially modular computational objects rather than indivisible networks.

### Level 4: universal latent interface

The strongest long-term result would be evidence for a model-independent atomistic representation interface

\[
Z(x)
\]

through which multiple pretrained models can communicate:

\[
M_A
\rightarrow
Z
\rightarrow
M_B.
\]

The recent observation of shared latent geometry among foundation MLIPs suggests that such interoperability is not implausible, although current evidence establishes geometric/algebraic compatibility rather than full functional interchangeability.

# 22. Working Thesis

The three projects can be summarized by one central thesis:

\[
\boxed{
\textbf{Pretrained atomistic representations may form reusable computational interfaces rather than model-specific hidden states.}
}
\]

Project I tests whether such an interface is **closed under additional computation**.

Project II tests whether its **depth can be selected according to task physics**.

Project III tests whether the interface can become **interoperable across independently pretrained models**.

A concise project title is therefore:

**Composable Latent Computation in Atomistic Foundation Models**

with the subtitle:

**Recursive Inference, Task-Dependent Depth, and Cross-Model Functional Stitching.**
